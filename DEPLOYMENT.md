# 🌸 ЦветыДляИннусика - Ежедневный чек-лист помощника

Персонализированный чек-лист для цветочного магазина с поддержкой русского и английского языков.

## ✨ Возможности

- 📋 4 категории задач с 35+ пунктами
- 🌐 Переключение между русским и английским языками
- 🎨 Автоматическая смена цветовой темы (розовая/синяя)
- 💾 Сохранение прогресса в localStorage
- 📱 Адаптивный дизайн для мобильных устройств
- 🔄 Автоматический сброс задач каждый день

## 🚀 Деплой на GitHub Pages

### Шаг 1: Создайте репозиторий на GitHub

1. Перейдите на [github.com](https://github.com)
2. Нажмите **"New repository"**
3. Введите имя репозитория (например, `flowers-checklist`)
4. Выберите **Public**
5. Нажмите **"Create repository"**

### Шаг 2: Загрузите код в репозиторий

```bash
# Инициализируйте git (если ещё не сделано)
git init

# Добавьте все файлы
git add .

# Сделайте первый коммит
git commit -m "Initial commit"

# Добавьте удалённый репозиторий
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git

# Отправьте код на GitHub
git branch -M main
git push -u origin main
```

### Шаг 3: Настройте vite.config.js для GitHub Pages

**ВАЖНО:** Перед деплоем нужно добавить `base` в `vite.config.js`:

Откройте файл `vite.config.js` и измените его так:

```javascript
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({
  plugins: [react(), tailwindcss()],
  base: '/YOUR_REPO_NAME/', // ← ДОБАВЬТЕ ЭТУ СТРОКУ (замените YOUR_REPO_NAME на имя вашего репозитория)
  server: {
    host: "0.0.0.0",
    port: 3000,
    strictPort: true,
    hmr: {
      port: 3000,
    },
  },
});
```

**Пример:** Если ваш репозиторий называется `flowers-checklist`, то строка будет:
```javascript
base: '/flowers-checklist/',
```

Закоммитьте изменения:
```bash
git add vite.config.js
git commit -m "Add base path for GitHub Pages"
git push
```

### Шаг 4: Включите GitHub Pages

1. Перейдите в ваш репозиторий на GitHub
2. Нажмите **"Settings"** (настройки)
3. В левом меню выберите **"Pages"**
4. В разделе **"Source"** выберите:
   - **Source:** GitHub Actions
5. GitHub автоматически запустит workflow из файла `.github/workflows/deploy.yml`

### Шаг 5: Проверьте деплой

1. Перейдите во вкладку **"Actions"** в вашем репозитории
2. Вы увидите запущенный workflow "Deploy to GitHub Pages"
3. Дождитесь завершения (обычно 1-2 минуты)
4. Когда workflow завершится успешно, ваше приложение будет доступно по адресу:
   ```
   https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/
   ```

## 🔄 Автоматический деплой

Теперь при каждом push в ветку `main` приложение будет автоматически пересобираться и деплоиться на GitHub Pages!

## 🛠️ Локальная разработка

```bash
# Установите зависимости
npm install

# Запустите dev-сервер
npm run dev

# Соберите production-версию
npm run build

# Предпросмотр production-версии
npm run preview
```

## 📱 Использование

1. Откройте приложение в браузере
2. Выберите язык (English/Русский) в правом верхнем углу
3. Отмечайте выполненные задачи кликом на кружок
4. Добавляйте заметки к задачам
5. Используйте фильтр для просмотра конкретных категорий
6. Нажмите "Новый день" для сброса всех задач

## 🎨 Особенности

- **Русский язык:** Синяя цветовая тема
- **Английский язык:** Розовая цветовая тема
- **Автоматический сброс:** Задачи сбрасываются каждый новый день
- **Локальное хранение:** Все данные сохраняются в браузере
