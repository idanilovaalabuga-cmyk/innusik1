## 🚀 Инструкция по деплою (5 минут)

### Шаг 1: Загрузите код в репозиторий

Откройте терминал в папке проекта и выполните:

```bash
# Инициализируйте git
git init

# Добавьте все файлы
git add .

# Сделайте первый коммит
git commit -m "Initial commit - ЦветыДляИннусика"

# Добавьте удалённый репозиторий
git remote add origin https://github.com/idanilovaalabuga-cmyk/innusik1.git

# Отправьте код на GitHub
git branch -M main
git push -u origin main
```

### Шаг 2: Включите GitHub Pages

1. Перейдите в ваш репозиторий: https://github.com/idanilovaalabuga-cmyk/innusik1
2. Нажмите **"Settings"** (настройки) в правом верхнем углу
3. В левом меню выберите **"Pages"**
4. В разделе **"Build and deployment"** → **"Source"** выберите:
   - **Source:** GitHub Actions
5. Готово! GitHub автоматически запустит деплой

### Шаг 3: Проверьте результат

1. Перейдите во вкладку **"Actions"** в вашем репозитории
2. Вы увидите запущенный workflow "Deploy to GitHub Pages"
3. Дождитесь завершения (обычно 1-2 минуты)
4. Когда появится зелёная галочка ✅, откройте:
   ```
   https://idanilovaalabuga-cmyk.github.io/innusik1/
   ```
